# Project instructions

## Emil Kowalski skills (installed from github.com/emilkowalski/skills)
Before animation, motion, interaction-polish or UI-engineering work, read the matching skill in `skills/`:
- `skills/emil-design-eng/SKILL.md` — design engineering principles (read for any UI polish)
- `skills/animate/SKILL.md` + `RECIPES.md` — adding animations
- `skills/animation-vocabulary/SKILL.md` — motion terminology
- `skills/find-animation-opportunities/SKILL.md` — where motion helps
- `skills/improve-animations/` — audit + plan for existing motion
- `skills/review-animations/` — review against STANDARDS.md
- `skills/apple-design/SKILL.md` — Apple-style design guidance
- `skills/prototype/` — prototyping workflow
- `skills/pick-ui-library/SKILL.md`, `skills/ask-sonner/` — library choice, Sonner toasts
- `performance-cheatsheet.md` — animation performance
Skipped (not applicable to web/HTML here): animate-expo, mobile-native, write-swift.

## Impeccable (installed from github.com/pbakaus/impeccable)
For design quality work, read `skills/impeccable/SKILL.md` first; it routes to `skills/impeccable/reference/<command>.md` (audit, critique, polish, typeset, colorize, layout, animate, distill, bolder, quieter, delight, harden, adapt, clarify, optimize, etc.). The CLI, live-browser scripts, hooks and native/iOS/Android references were not copied, since they need a local runtime; skip any step that depends on them.
