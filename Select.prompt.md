One-line: the single-line text control — 6px radius, hairline border, terracotta focus ring.

```jsx
<Input placeholder="(38) 99999-9999" />
<Input type="number" prefix="R$" step="0.01" defaultValue="0" />
```

The border is the affordance; there is no filled variant. Focus = accent border + 3px terracotta glow.
